# ACME Provider Long-Term Maintenance Notice

The ACME provider is now in long-term maintenance.

The current feature set will continue to be maintained (including additional
bug fixes if necessary), and the provider will continue to keep up to date with
the latest lego versions, for as long as possible.

No new major features will be added; this includes support for any additional
extensions to the ACME specification standard, features implemented by lego, or
Terraform features (this includes write-only arguments).

Please keep this in mind when submitting an issue.
